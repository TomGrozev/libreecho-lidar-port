# Phase 0: experimental workspace

Phase 0 closed the workspace gate so the later phases start from known repositories
and tools. It confirmed the layout, the product start commit and the current heads of
each owning repository. It then cloned the required repositories, created the local
`feature/lidar-support` branches, and recorded the host dependencies (Python version,
mtkclient commit, tool versions). Nothing was pushed or forked. `notes.md` is the full
record.
